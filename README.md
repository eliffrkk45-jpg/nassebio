# NASSE BIOLOGY

Mavi-yeşil temalı, mobil uyumlu biyoloji mini oyun sitesi. HTML, CSS ve JavaScript ile hazırlanmıştır.

## Bilgisayarda çalıştırma
1. ZIP dosyasını çıkar.
2. `nasse_biology` klasörünü VS Code ile aç.
3. `index.html` dosyasını tarayıcıda aç. Daha rahat geliştirme için VS Code'da Live Server eklentisini kullanabilirsin.

## İçerik
- Reseptör eşleştirme oyunu
- Çoktan seçmeli hızlı tur
- Yazılı cevap / kelime bilmeceleri
- Nöron tasarım atölyesi
- Zar potansiyeli sıralama simülasyonu
- Açılır bilgi arşivi
- XP, görev ilerlemesi ve localStorage ile aynı tarayıcıda kayıt
- Telefon ve masaüstü için responsive tasarım

## Geliştirme notları
- İlerleme şu an kullanıcının kendi tarayıcısında saklanır; hesaplar ve cihazlar arası senkronizasyon için bir backend gerekir.
- Harici fontlar için internet bağlantısı gerekebilir. Font yüklenmezse sistem fontları kullanılır.
- Bu bir başlangıç sürümüdür. Öğretmeninle güncel 11. sınıf Türkiye Yüzyılı Maarif Modeli kazanımlarına göre içerik doğrulaması yap.
